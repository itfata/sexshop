# Підключення замовлень до KeyCRM

Сайт залишається статичним на GitHub Pages. API-ключ KeyCRM зберігається лише у Cloudflare Worker і ніколи не потрапляє у браузер або GitHub.

## Що вже реалізовано

- перевірка контактних даних і товарів на сервері;
- серверна перевірка назв і цін за каталогом `products.js` — змінити суму через браузер неможливо;
- передавання покупця, телефону, email, міста, відділення Нової пошти, коментаря, UTM-міток і складу кошика;
- товари передаються без артикулів;
- повідомлення про успіх показується лише після відповіді KeyCRM;
- при помилці локальна чернетка зберігається для повторної спроби;
- API-ключ закритий у секреті Worker;
- дозволені запити тільки з домену магазину та локального середовища розробки.

## Дані, які потрібно отримати в KeyCRM

1. Створіть окреме джерело замовлень, наприклад `Сайт`.
2. Запишіть його числовий `source_id`. Його також можна отримати запитом `GET https://openapi.keycrm.app/v1/order/source`.
3. Створіть API-ключ у налаштуваннях KeyCRM.

Не надсилайте API-ключ у відкритий чат і не додавайте його до `config.js`.

## Розгортання захищеного Worker

Потрібен обліковий запис Cloudflare. У каталозі `keycrm-worker` виконайте:

```bash
npm install
npx wrangler login
npx wrangler secret put KEYCRM_API_KEY
npx wrangler secret put KEYCRM_SOURCE_ID
npm run deploy
```

Після розгортання Cloudflare покаже адресу на кшталт:

```text
https://sexshop-keycrm-orders.<ваш-піддомен>.workers.dev
```

Вкажіть її у `config.js`, додавши `/orders`:

```js
window.STORE_CONFIG = {
  orderApiUrl: "https://sexshop-keycrm-orders.<ваш-піддомен>.workers.dev/orders"
};
```

Перед бойовим запуском перевірте одне тестове замовлення та налаштуйте в Cloudflare обмеження частоти запитів для маршруту `/orders`. KeyCRM допускає до 20 запитів на хвилину для одного API-ключа.

Після кожного оновлення `products.js` команда `npm run deploy` автоматично оновлює захищену копію назв і цін у Worker.

## Локальна перевірка

Скопіюйте `.dev.vars.example` у `.dev.vars`, підставте тестові значення та виконайте:

```bash
npm install
npm test
npm run dev
```

Файл `.dev.vars` виключений з Git і не публікується.
