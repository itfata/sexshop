# Підключення приймання замовлень

Сайт надсилає замовлення серверним запитом з `index.php` до LP-CRM. У замовлення потрапляють контакти клієнта, місто та відділення Нової пошти, коментар, усі товари з кошика, сума й UTM-мітки. Після успішної передачі сайт також надсилає повідомлення на email з наданого обробника. Підтримка Telegram перенесена, але для її ввімкнення потрібні справжні `telegram_bot_token` і `telegram_chat_id`: у вихідному файлі замість них були заглушки.

1. Завантажте всю папку сайту на хостинг із PHP 8.1+ та розширенням cURL.
2. Поруч з `index.php` має бути файл `lp-crm-config.local.php` з робочим ключем. Він уже підготовлений у локальній папці для передачі клієнту.
3. Відкривайте сайт через `index.php` або налаштуйте його як головний index-файл.
4. Зробіть тестове замовлення та перевірте його появу в LP-CRM.

GitHub Pages не запускає PHP. На GitHub магазин можна переглядати, але реальна відправка замовлень працює лише на PHP-хостингу.
